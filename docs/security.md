# Mercury Security

Комплексная система защиты сервера. Mercury обнаруживает подозрительную активность, **автоматически блокирует действие**, наказывает нарушителя, уведомляет администрацию и сохраняет инцидент в базу.

::: callout warning "Важно"
Это не просто логирование. При срабатывании защиты Mercury сам наказывает нарушителя: снимает роли, выдаёт тайм-аут, кикает или банит — в зависимости от серьёзности угрозы.
:::

---

## Быстрый старт

1. Включите систему: `/security-settings система включить:Да` или на сайте в разделе **Безопасность**
2. Установите канал алертов: `/security-settings канал канал:#безопасность`
3. (Необязательно) Укажите роль для пинга: `/security-settings роль роль:@Security`
4. Проверьте статус: `/security`

```
Mercury обнаружил угрозу → заблокировал действие → наказал нарушителя
→ отправил алерт в канал → сохранил инцидент в журнал
```

## Модули защиты

### 🛡️ Anti-Nuke

Защита от деструктивных действий участников с правами администратора:

| Угроза | Порог (за 10 сек) | Реакция |
|---|---|---|
| Удаление каналов | 3 | Снятие ролей + бан |
| Создание каналов | 5 | Снятие ролей + кик |
| Удаление ролей | 3 | Снятие ролей + бан |
| Создание ролей | 5 | Снятие ролей + кик |
| Баны участников | 3 | Снятие ролей + бан |
| Кики участников | 3 | Снятие ролей + кик |
| Выдача ролей | 5 | Снятие ролей + кик |

**Мгновенная реакция** (без порога, при любой выдаче):
- Выдача роли с правами Administrator, ManageGuild, ManageRoles, BanMembers, KickMembers
- Выдача любой роли боту
- Изменение прав роли на опасные
- Изменение vanity URL сервера

### 🚪 Anti-Raid

Защита от массовых заходов ботов на сервер:

- **5 участников за 10 секунд** → автоматический локдаун сервера
- Во время локдауна: у `@everyone` снимается право создавать приглашения, все инвайты удаляются, новые участники кикаются
- **Alt-детект**: аккаунты младше 3 дней кикаются с сообщением о защите
- Локдаун снимается автоматически через 10 минут (настраивается) или вручную: `/security-lockdown off`

### 📢 Anti-Spam

- **7 сообщений за 5 секунд** → тайм-аут 24ч + удаление сообщений
- **3 одинаковых сообщения подряд** → тайм-аут 24ч
- **8+ упоминаний** в одном сообщении → удаление + тайм-аут

### 🤖 Anti-Bot

- Добавление бота на сервер участником без whitelist → бот **мгновенно кикается**, добавивший наказывается
- Серьёзность: критическая

### 🔗 Anti-Link

Блокировка вредоносных ссылок и файлов:

- Подделки Discord и Steam (`discord-nitro.xyz`, `steamcomunity.ru` и т.п.)
- Известные token grabber домены (grabify, iplogger и т.д.)
- «Бесплатные нитро» в любом виде
- Опасные вложения: `.exe`, `.scr`, `.bat`, `.msi`, `.apk` и другие

При обнаружении: сообщение удаляется, нарушитель получает тайм-аут, инцидент сохраняется.

## Whitelist

Участники в whitelist имеют иммунитет — их действия не блокируются. Mercury только **уведомляет** администрацию о подозрительной активности (monitor mode).

::: callout info "Владелец сервера"
Владелец сервера всегда имеет иммунитет и не может быть добавлен/удалён из whitelist.
:::

**Команды:**

| Команда | Описание |
|---|---|
| `/security-whitelist add пользователь:@user` | Добавить в whitelist |
| `/security-whitelist remove пользователь:@user` | Убрать из whitelist |
| `/security-whitelist list` | Показать список |

## Лестница наказаний

| Серьёзность | Угрозы | Наказание |
|---|---|---|
| Низкая | Спам | Тайм-аут 10 минут |
| Средняя | Флуд, дубликаты, alt | Снятие ролей + тайм-аут 24ч |
| Высокая | Массовые кики, создание каналов/ролей, grabber | Снятие ролей + кик |
| Критическая | Массовые удаления/баны, опасные права, добавление ботов | Снятие ролей + бан |

Если бот не может исполнить наказание (иерархия ролей), отправляется экстренный алерт с пометкой **«НЕ СМОГ НАКАЗАТЬ»** и упоминанием владельца сервера.

## Команды

| Команда | Описание | Права |
|---|---|---|
| `/security` | Статус системы, модули, счётчики инцидентов | Администратор |
| `/security-settings` | Настройка порогов, модулей, канала, роли | Администратор |
| `/security-whitelist` | Управление whitelist | Администратор |
| `/security-incidents` | Журнал инцидентов с пагинацией | Администратор |
| `/security-lockdown on/off` | Ручной локдаун сервера | Администратор |

### `/security-settings` — параметры

| Подкоманда | Пример |
|---|---|
| `параметр` | `настройка:Удалений каналов значение:5` |
| `модуль` | `модуль:Anti-Nuke включить:Нет` |
| `система` | `включить:Да` |
| `канал` | `канал:#логи-безопасности` |
| `роль` | `роль:@Security` |

Все пороги также настраиваются на сайте в разделе **Безопасность**.

## Частые вопросы

**Защитит ли Mercury от скомпрометированного аккаунта администратора?**
Да — это основной сценарий. Если взломанный админ начнёт удалять каналы или банить всех, Mercury снимет с него роли и забанит за считанные секунды.

**Что если Mercury забанит легитимного админа?**
Добавьте его в whitelist. Тогда Mercury будет только уведомлять о его действиях, не блокируя их.

**Был ложный локдаун, как снять?**
`/security-lockdown off` — право создавать приглашения восстановится сразу.

**Почему не определяется нарушитель?**
Для чтения audit log боту нужно право **Просмотр журнала аудита** (ViewAuditLog). Также записи появляются с задержкой до 2 секунд.
