# Добро пожаловать в документацию MercuryBot

**MercuryBot** — это многофункциональный Discord-бот, разработанный для повышения вовлечённости пользователей и упрощения управления сервером. Бот сочетает в себе глубокую экономическую систему, социальные функции, продвинутую систему уровней и мощные инструменты модерации.

---

## Основные возможности

::: card "💰 Экономика"
Валюта, банк, магазин ролей, работа (10 уровней должностей), ежедневные/еженедельные/ежемесячные бонусы, казино с космическими символами и мини-игры.
:::

::: card "📊 Уровни и XP"
Начисление опыта за сообщения и голосовую активность. Визуальные карточки ранга и профиля (эмбед или canvas-изображение).
:::

::: card "💍 Социальные функции"
Браки с прокачкой и баллами, любовные комнаты, квесты (15 квестов в 4 категориях), достижения и настраиваемые профили.
:::

::: card "🛡️ Модерация"
Ban, mute, warn с авто-наказаниями, автомодерация плохих слов, временные роли и расширенное логирование (11 категорий).
:::

::: card "⚙️ Гибкая настройка"
Обширная панель настроек через `/set`, интерактивный мастер `/setup`, кастомизируемая валюта для каждого сервера и веб-дашборд.
:::

::: card "🎤 Приватные комнаты"
Автоматическое создание и управление временными голосовыми каналами с полным набором управления.
:::

::: card "🌐 Веб-дашборд"
Полноценная веб-панель управления настройками бота с Discord OAuth2 авторизацией и дружественным интерфейсом.
:::

::: card "🔌 REST API"
Внешнее API для интеграции с другими ботами и сервисами. Управление балансом пользователей через HTTP-запросы.
:::

## Технологический стек

| Технология | Назначение |
|---|---|
| **Node.js** | Серверная платформа |
| **Discord.js v14** | Взаимодействие с Discord API |
| **MongoDB (Mongoose)** | База данных |
| **Hono** | Веб-сервер для REST API и дашборда |
| **@napi-rs/canvas** | Генерация изображений (профили, браки) |
| **Canvacord** | Генерация карточек ранга |
| **Moment.js** | Обработка дат и времени |
