# Команды администрирования

Команды для настройки MercuryBot под ваш сервер. Все команды требуют прав **Администратор**.

::: callout danger "Доступ"
Все команды в этом разделе доступны только пользователям с правом **Администратор** (Administrator) на сервере.
:::

---

## Настройка бота — `/set`

Универсальная команда настройки всех систем бота. Содержит множество подкоманд.

### Каналы

| Подкоманда | Описание |
|---|---|
| `/set notifychannel` | Установить канал для оповещений бота |
| `/set reportchannel` | Установить канал для приёма жалоб |

### Модерация

| Подкоманда | Описание |
|---|---|
| `/set warn` | Установить максимальное количество варнов |
| `/set autopunish` | Настройка авто-наказаний за варны |

**Авто-наказания:**

| Действие | Описание |
|---|---|
| Тайм-аут (1ч) | Мут на 1 час |
| Тайм-аут (24ч) | Мут на 24 часа |
| Кик | Кик с сервера |
| Бан | Бан на сервере |
| Сбросить | Отключить авто-наказания |

### Учётные записи

| Подкоманда | Описание |
|---|---|
| `/set account` | Изменить информацию аккаунта пользователя |

**Доступные настройки:**
- Количество варнов
- Уровень
- XP (опыт)
- Монеты

### Система уровней

| Подкоманда | Описание |
|---|---|
| `/set leveling` | Настройка системы уровней |

**Параметры:**

| Настройка | Описание |
|---|---|
| Игнор канал | Канал, где не начисляется XP |
| Множитель опыта | Множитель для начисляемого XP |
| Максимальный уровень | Лимит уровня |
| XP за сообщения | Количество XP за сообщение |
| XP за войс (в минуту) | Количество XP за минуту в голосе |
| Шаг награды (XP) | Каждые N XP — награда |
| Сумма награды (монеты) | Сколько монет давать за награду |

### Приватные комнаты

| Подкоманда | Описание |
|---|---|
| `/set private` | Настройка приватных каналов |

**Параметры:**

- **Категория** — категория для создания приватных каналов
- **Канал создания приватов** — голосовой канал-триггер
- **Канал управления приватами** — текстовый канал с панелью

### Тикеты

| Подкоманда | Описание |
|---|---|
| `/set ticket` | Настройка системы тикетов |

**Параметры:**

| Настройка | Описание |
|---|---|
| Тикет канал | Канал с панелью создания тикетов |
| Интервал на создание | Кулдаун между тикетами (в минутах) |
| Канал лог тикетов | Канал для логов тикетов |
| Текст сообщения | Текст в панели создания |
| Текст при создании | Текст внутри созданного тикета |
| Роль агента поддержки | Роль, добавляемая в тикет |

### Авто-модератор

| Подкоманда | Описание |
|---|---|
| `/set automoder` | Настройка автомодератора |

**Параметры:**

- **Канал лог** — канал для логов автомодерации
- **Плохое слово** — добавление слова в фильтр
- **Модераторская роль** — роль модераторов
- **Игнорируемый канал** — канал, где автомодерация не работает

### Логирование

| Подкоманда | Описание |
|---|---|
| `/set logs` | Настройки логирования |

**Типы логов (11 категорий):**

| Тип | Описание |
|---|---|
| Действия с ролями | Создание, удаление, изменение ролей |
| Действия с каналами | Создание, удаление, изменение каналов |
| Действия с сообщениями | Редактирование, удаление сообщений |
| Приватные комнаты | Создание, удаление приватных голосовых каналов |
| Изменения сервера | Общие настройки сервера |
| Изменение участников | Вход, выход, обновление ролей участников |
| Наказания | Варны, муты, кики |
| Тикеты | Создание, закрытие тикетов |
| Голосовые каналы | Подключения, отключения, перемещения |
| Экономика | Работа, бонусы, переводы, трансферы |
| Баны | Баны и разбаны |

::: callout tip "Отключение логов"
Чтобы отключить определённый тип логов, укажите `off` вместо канала.
:::

| Уровни | Система XP и рангов |

| Ежедневная статистика в войсе | Статистика голосовой активности |

:::

| Параметр | Описание |

## Веб-дашборд

MercuryBot включает полноценную веб-панель управления настройками, доступную через браузер.

### Возможности дашборда:

- **Авторизация** через Discord (OAuth2)
- **Выбор сервера** из списка доступных
- **11 категорий настроек** с мгновенным сохранением:
  - Системы — включение/отключение модулей
  - Модерация — варны, авто-наказания
  - Экономика — бонусы, зарплаты, валюта
  - Уровни — множители, награды
  - Тикеты — каналы, роли, кулдауны
  - Приваты — категория, каналы
  - Любовные комнаты — настройки и исключения
  - Браки — цены, роли, стиль профиля
  - Автомодерация — слова, каналы
  - Логирование — 11 категорий
  - Голос — исключения, статистика
- **Тёмная и светлая темы** (или системная)
- **Поиск** по настройкам
- **Адаптивный дизайн** для мобильных устройств

## REST API

MercuryBot предоставляет REST API для интеграции с внешними сервисами и ботами.

### Базовая информация:

| Параметр | Значение |
|---|---|
| **Базовый URL** | `http://localhost:3000` (порт настраивается через `API_PORT`) |
| **Авторизация** | Bearer-токен через заголовок `Authorization` |
| **Токен** | Настройте через `API_TOKEN` в `.env` |

### Эндпоинты:

#### Получить баланс пользователя

```
GET /api/balance/:guildId/:userId
```

**Ответ:**
```json
{
  "guildId": "123456789",
  "userId": "987654321",
  "money": 1000,
  "bank": 500
}
```

#### Добавить монеты

```
POST /api/balance/:guildId/:userId/add
```

**Тело запроса:**
```json
{
  "amount": 500
}
```

#### Забрать монеты

```
POST /api/balance/:guildId/:userId/remove
```

**Тело запроса:**
```json
{
  "amount": 200
}
```

**Ошибка (400):** Если у пользователя недостаточно средств.

### Примеры (cURL):

```bash
# Получение баланса
curl -X GET http://localhost:3000/api/balance/SERVER_ID/USER_ID \
     -H "Authorization: Bearer YOUR_TOKEN"

# Добавление монет
curl -X POST http://localhost:3000/api/balance/SERVER_ID/USER_ID/add \
     -H "Authorization: Bearer YOUR_TOKEN" \
     -H "Content-Type: application/json" \
     -d '{"amount": 100}'
```

## Быстрый старт настройки

::: callout tip "Рекомендуемый порядок настройки"
1. `/set notifychannel` — канал оповещений
2. `/set logs` — логирование (11 категорий)
3. `/set leveling` — система уровней
4. `/set systems` — включить нужные системы
5. `/set economy` — кастомизация валюты
6. `/set private` — приватные комнаты
7. `/set ticket` — тикеты
8. `/set automoder` — автомодерация
9. `/send-private` — панель приватов
10. `/send-ticket` — панель тикетов
11. `/add-shop-item` — магазин ролей
:::
