# Команды модерации

Инструменты для управления сервером и поддержания порядка.

::: callout warning "Права доступа"
Команды модерации требуют соответствующих прав Discord. Убедитесь, что у модераторов есть необходимые разрешения.
:::

---

## Наказания

### `/ban`

Забанить пользователя на сервере.

| Параметр | Описание |
|---|---|
| `пользователь` | Кого забанить (обязательно) |
| `время` | Длительность бана, например `1h`, `1d`, или `0` для перманентного (обязательно) |
| `причина` | Причина бана (необязательно) |

**Требуемые права:** Банить участников (BanMembers)

---

### `/unban`

Снять бан с пользователя по его ID.

| Параметр | Описание |
|---|---|
| `пользователь` | ID пользователя (обязательно) |
| `причина` | Причина разбана (необязательно) |

**Требуемые права:** Банить участников (BanMembers)

::: callout info "Почему ID?"
Забаненные пользователи не видны на сервере, поэтому их нельзя выбрать через меню. Используйте ID пользователя — скопируйте его из логов или через режим разработчика.
:::

---

### `/mute`

Выдать временную блокировку (тайм-аут) пользователю.

| Параметр | Описание |
|---|---|
| `пользователь` | Кого замьютить (обязательно) |
| `время` | Длительность, например `1m`, `1h`, `1d` (обязательно) |
| `причина` | Причина (необязательно) |

**Требуемые права:** Модерировать участников (ModerateMembers)

---

### `/unmute`

Снять тайм-аут с пользователя.

| Параметр | Описание |
|---|---|
| `пользователь` | С кого снять мут (обязательно) |
| `причина` | Причина (необязательно) |

**Требуемые права:** Модерировать участников (ModerateMembers)

---

### `/warn`

Выдать предупреждение (варн) пользователю.

| Параметр | Описание |
|---|---|
| `пользователь` | Кому выдать варн (обязательно) |
| `причина` | Причина (необязательно) |

**Требуемые права:** Кикать участников (KickMembers)

::: callout tip "Авто-наказания"
Настройте автоматические наказания за превышение лимита варнов через `/set autopunish`. При достижении лимита варнов бот автоматически применит наказание.
:::

**Доступные авто-наказания:**

| Действие | Описание |
|---|---|
| Тайм-аут (1ч) | Мут на 1 час |
| Тайм-аут (24ч) | Мут на 24 часа |
| Кик | Кик с сервера |
| Бан | Бан на сервере |
| Сбросить | Отключить авто-наказания |

---

## Управление чатом

### `/clear`

Очистить сообщения в текущем канале.

| Параметр | Описание |
|---|---|
| `число` | Количество сообщений для удаления (обязательно, максимум 100) |

**Требуемые права:** Управлять сообщениями (ManageMessages)

::: callout info "Ограничение Discord"
Discord API позволяет удалять не более 100 сообщений за один раз. Сообщения старше 14 дней не могут быть удалены массово.
:::

---

### `/embed`

Отправить сообщение от имени бота в виде Embed (встроенного сообщения).

| Параметр | Описание |
|---|---|
| `канал` | Канал для отправки (обязательно) |
| `заголовок` | Заголовок Embed (обязательно) |
| `цвет` | Цвет в HTML-коде, например `#FF0000` (обязательно) |
| `текст` | Текст сообщения, до 2000 символов (обязательно) |
| `подпись` | Подпись внизу Embed (обязательно) |

**Требуемые права:** Управлять сообщениями (ManageMessages)

## Временные роли

### `/add-timerole`

Выдать временную роль пользователю на определённое время.

| Параметр | Описание |
|---|---|
| `пользователь` | Кому выдать роль (обязательно) |
| `время` | Длительность: `s` (сек), `m` (мин), `h` (час), `d` (дни) (обязательно) |
| `причина` | Причина (необязательно) |

**Требуемые права:** Управлять ролями (ManageRoles)

::: callout warning "Позиция роли"
Роль бота должна быть выше выдаваемой временной роли. Иначе бот не сможет её выдать.
:::

---

### `/set-timerole`

Настройка системы временных ролей.

**Требуемые права:** Управлять ролями (ManageRoles)

::: callout info "Автоматическое снятие"
После истечения времени роль автоматически снимается с пользователя. Бот проверяет истекшие роли каждые несколько минут.
:::

## Автомодерация

MercuryBot включает встроенную систему автоматической модерации, которая сканирует сообщения на наличие запрещённых слов.

### Что делает автомодератор:

- Сканирует все сообщения на наличие слов из чёрного списка
- При обнаружении — удаляет сообщение и уведомляет модераторский канал
- Отслеживает количество нарушений пользователя
- Работает в каналах, не входящих в список исключений

### Настройка через `/set automoder`:

| Параметр | Описание |
|---|---|
| Канал лог | Канал для уведомлений о нарушениях |
| Плохое слово | Добавление слова в фильтр |
| Модераторская роль | Роль, уведомления получают модераторы |
| Игнорируемый канал | Канал, где фильтр не работает |

## Логирование

MercuryBot поддерживает **11 категорий логирования** — подробное отслеживание всех действий на сервере.

### Настройка через `/set logs`

Для каждой категории укажите канал для логов. Чтобы отключить категорию, укажите `off`.

### Категории логов:

| Категория | Описание |
|---|---|
| **Действия с ролями** | Создание, удаление, изменение ролей |
| **Действия с каналами** | Создание, удаление, изменение каналов |
| **Действия с сообщениями** | Редактирование, удаление сообщений |
| **Приватные комнаты** | Создание, удаление приватных голосовых каналов |
| **Изменения сервера** | Общие настройки сервера |
| **Изменение участников** | Вход, выход, обновление ролей участников |
| **Наказания** | Варны, муты, кики |
| **Тикеты** | Создание, закрытие тикетов |
| **Голосовые каналы** | Подключения, отключения, перемещения |
| **Экономика** | Работа, бонусы, переводы, трансферы |
| **Баны** | Баны и разбаны |

::: callout tip "Отключение логов"
Чтобы отключить определённый тип логов, укажите `off` вместо канала.
:::

::: callout info "Аудит-логи"
Для некоторых категорий (роли, каналы) бот использует аудит-логи Discord для определения кто именно совершил действие.
:::
